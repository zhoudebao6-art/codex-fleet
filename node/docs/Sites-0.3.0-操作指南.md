# Codex Fleet Sites 功能说明（历史版本）

新电脑接入及 0.3.6 安装请先阅读 [部署使用指南](部署使用指南.md)。以下保留各版本功能背景，不作为当前安装入口。

0.3.2 为网站明确新建或选择、且已由目标电脑核验目录的项目增加 Codex 项目关联。节点通过本机 App Server 项目接口匹配真实目录，复用或登记内部项目 ID，并为新 Fleet 任务设置短标题和 `codex://threads/<threadId>` 本机打开入口。续接任务保留原会话；已有桌面会话不会被接管。登记不支持或失败时明确显示原因，任务仍按原已核验目录和权限运行；若新任务返回的项目关联与预期不符，则不开始任务。

“已登记”表示 App Server 项目接口及持久关联已核验，不代表桌面侧栏已显示。当前本机实验中原生任务读取可用，但原生项目列表尚未显示新登记目录，官方 `codex app <目录>` 打开命令也未证明侧栏同步；因此状态仍为 `visibility=not_verified`。其他电脑点击任务链接只能打开该电脑自己的 Codex，不能凭此链接访问远端本地文件。已有多目录项目不会自动扩大网站所选目录的权限范围。

0.3.1 增加节点独立维护通道。首次从旧版原目录升级后，管理员可在网站设备详情发起后续升级：节点自动下载网站已登记版本，校验文件，等待当前工作及队列完成，再备份升级；失败回滚并上报。升级不消耗 Codex 模型，不依赖模型代执行安装命令。动作持久去重，执行结果不确定时保留证据，不擅自再次安装。电脑睡眠或离线时等待其恢复。

网站显示名和业务分组用于组织设备，稳定 PC 代号、节点 ID 和 Codex 账号并发分组保持独立。新设备从网站生成自己的邀请，不能复制既有电脑的身份配置。

当前部署以 Sites 网站为总控。每台 Windows 电脑主动同步，不需要开放入站端口或安装本地 Hub；Tailscale 可以保留。同账号和不同账号的电脑均使用独立节点身份，保留原 Codex 登录、技能、MCP、项目和启动方式。

## 已接入电脑升级

不要重装或复制另一台电脑的 config/data。取得完整 Windows ZIP 与发布的 SHA256，解压到独立目录，用原 Codex 所属 Windows 用户执行：

```powershell
& '<解压目录>\scripts\Update-Fleet.ps1' -PackagePath '<完整ZIP路径>' -Sha256 '<发布的64位SHA256>' -InstallDir 'D:\CodexFleet' -Queue
```

脚本核对清单，暂缓接收新任务，等待当前任务、文件和事件队列完成，备份后替换程序并恢复服务。失败回滚程序；身份、数据库、登录及其他技能保留。`-VerifyOnly` 只核对包。

0.2.0 遇到本机命令审批会中断，无法借自身任务完成首次升级；在该电脑原有本地 Codex 会话执行一次升级即可。不要覆盖配置或关闭全局安全设置绕过。

## 新电脑接入

网站设备管理为每台电脑生成独立邀请。将邀请与安装包交给目标电脑，解压后运行 `Setup-Sites.cmd`。已有节点必须使用原安装目录；不要建立重复身份。安装包自带 Node.js，不含网站密码、节点口令和 Codex 凭据。

## 日常使用

- 工作台按设备查看当前任务、最近活动、实际传输进度和需要处理的事项，右侧阅读详情。
- 任务目录汇总 Fleet 与原生 Codex 任务，支持搜索、归档筛选和固定主要任务。同步目录和最近公开消息，不含隐藏推理、凭据、完整工具原文。
- 派发时选电脑和已登记项目，也可新建项目；节点确认真实目录后才可执行。项目总控绑定用于提供公开背景和自动化备注，不接管正在运行的原生聊天。
- 自动流程支持 2–12 步，分别指定电脑、项目、任务、产物。前一步提交且产物完整后，自动交付下一步。提交不等于业务验收；失败、受阻、不确定时暂停后续步骤，避免重复副作用。
- 执行任务可沿用本机 Codex 权限；提问始终只读。需要确认的请求在网页显示，系统不自行同意权限扩展和连接器授权。
- 文件按真实字节显示进度，断线保留偏移，完成校验 SHA256。单文件默认 512 MiB；更大目录可生成分卷压缩包逐卷传输。不要上传密钥或 Codex 配置目录。

## 免密码入口

使用已接入电脑的桌面 `Codex Fleet Console`。0.3.0 节点提供仅本机可用的 `http://127.0.0.1:43129/login`，获取短时一次性票据后跳转网站。网站自动发现受浏览器限制时，点击登录页“已接入电脑 · 免登录进入”。手机及未接入设备使用网站账号。节点必须运行；电脑名称、IP 或网址参数不能替代身份验证。

## 恢复与自动总控

节点在原 Windows 用户登录后启动。离线展示最近心跳与同步时间，不伪装实时。网络恢复补发持久化事件和文件；执行进程意外退出的任务标记结果不确定，不盲目重跑。交互答复确认丢失时只重传确认，不重复批准。

新开 Codex 会话加载 `codex-fleet` 技能和 MCP。总控通过 `fleet_nodes`、`fleet_desktop_tasks`、`fleet_projects`、`fleet_automation_create` 等接口查询和编排，继续使用目标电脑自己的技能。

旧 Hub/Tailscale 路线见 `旧版私网部署指南.md`，不要与 Sites 安装步骤混用。具体实体机升级及验证结果以本次发布报告为准。
