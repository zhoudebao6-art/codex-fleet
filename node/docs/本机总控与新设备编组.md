# 本机总控与新设备编组

网站主控按批次分配材料，各电脑的原总控负责本机子任务；成果仍由主控核验并汇总。

1. 新电脑使用网站生成的安装接入包，保留原 Codex 账号、技能、项目和目录。
2. 节点自动同步项目、技能目录及桌面执行能力。打开联动入口后，网站“自动交付 → 设备协同能力”显示读取状态。
3. 主控设置启用新设备评估，且主控电脑已绑定自动化 2.0 总控时，新增可用设备会触发一次只读协同评估。
4. 主控核实当地原流程并在选中的原对话探测；真实回复完成后登记绑定。候选不明确时保留待编组，不派业务任务。
5. 网页可按自动化类型修改每台电脑的项目及总控对话。变更只用于后续批次；正在运行的批次保留原绑定和成果。
6. 开始交付时先核对 GitHub 固定版本。当地总控复用既有工具与配置，逐项提交固定编号子任务，使用独立案件子目录，允许并行。
7. 网页分别显示原总控接单、子任务执行和文件回传。总控消息送达不能作为成品完成证明。

主控可参与制作，也可只负责分发和汇总。被排除的设备不会被自动评估或启用。暂停、取消、断线和不确定发送均保留固定编号；不得通过重新发一批来掩盖失败。

0.3.19 安装包包含主控登记脚本与此协作规范。网站的原对话路由兼容已启用桌面共享的 0.3.16 以上节点，无需为本次网站升级中断在制任务。
