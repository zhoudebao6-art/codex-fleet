# 电源与账号切换（0.3.14）

新安装的节点会同时启动独立电源组件。现有运行中的节点可以先使用电源增量包接入，不必退出 Codex 或停止正在执行的任务。组件身份沿用节点身份，不复制或依赖 Codex 登录。

默认接电时保持可调度：阻止 Windows 因空闲而自动休眠，允许关闭屏幕。电池供电时只在确认有任务或传输时保持唤醒。管理员可以在设备资料的“电源与唤醒”中切换为“仅工作和传输期间”或关闭。手动睡眠、合盖、断电、关机仍受 Windows、硬件和电源策略控制。守护异常退出或租约到期会释放电源请求，不修改整机电源计划。

自动检测只使用物理网卡，排除 VPN/Tailscale 地址。使用物理网关 MAC、IPv4 子网和前缀形成局域网标识；不能只用业务分组或相同的 192.168 地址判定同一网络。没有可核实的网关身份时不自动猜测。

自动配置会保存原设置，并使用不重启网卡的接口尝试启用魔术包唤醒。权限不足、驱动拒绝或 BIOS 未启用会如实显示；不修改 BIOS、不重启网卡、不关闭正在运行的任务，不自动开启系统休眠文件。无需新开防火墙入站端口。

网页“唤醒电脑”由目标同一局域网内在线的 Fleet 电脑发送有限次数的 UDP 魔术包。异地通过 Sites HTTPS 下达给当地中转，云端无需直接访问内网。目标局域网没有在线节点时需要当地路由器等另行提供唤醒能力；仅安装 Tailscale 不能使已休眠的电脑执行指令。当前不自动登录或改动路由器。

“检测唤醒链路”用于在线目标，不使目标休眠。发送包通过只证明中转确实发包；真实唤醒必须看到请求之后新的节点心跳和 Codex 就绪。超时不会无限重试，也不重发业务任务。网站操作员仅能请求自己授权范围内的设备；电源策略只能由管理员更改。

总控工具：`fleet_power` 查询检测、守护与唤醒记录；`fleet_wake` 请求唤醒，提供稳定 id，结果未知时复用同一个 id。在线链路测试显式使用 probe=true。

切换 Codex 账号时保留 Fleet 安装和节点身份。节点在空闲时重新读取账号和技能，退出登录期间不领取新任务；新账号就绪后更新并发组。执行前再次比对账号，若派发后账号已经改变则明确失败，不能把原任务偷偷换号重跑。电源守护、网站连接和文件队列继续使用原节点身份。登录失效仍需在当地正常登录，Fleet 不替代账号验证，也不关闭业务对话。

停止全部 Fleet 组件使用 `Disable-Fleet.ps1`。单独停止电源组件可在该安装的 `data\node\power` 目录写入 `stop.request`；它会释放防休眠请求并退出，不停止 Codex。再次运行 `Start-FleetPower.ps1` 可恢复。
